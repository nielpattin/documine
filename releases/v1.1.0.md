# DocuMine v1.1.0

**Released:** May 12, 2026

Adds an in-editor note explorer for faster navigation, performance improvements for note opening and preview rendering, and a major internal restructuring for maintainability.

---

## What's New

### In-Editor Note Explorer

Keep note navigation available without leaving the editor. A sidebar panel lets you browse, switch, and create notes directly inside the editing view.

### Performance Improvements

- **Faster note opening** — removed redundant auth checks and deferred hidden preview work that were delaying editor mount.
- **Stale PDF previews eliminated** — switching notes no longer flashes the previous note's PDF content while the new one loads.

### Internal Restructuring

The monolithic 3000+-line `App.tsx` has been split into dedicated page components (`LoginPage`, `NotesListPage`, `OwnerNotePage`, `SharedNotePage`), feature modules (`clipboard`, `comments`, `preview`, `PDF export`), and shared UI primitives. The server and PDF export modules were refactored to match the new boundaries. This makes the codebase navigable and each module independently testable.

### Developer Experience

- Migrated package manager from npm to pnpm for faster installs and stricter dependency management.
- Docker builds now cache bundled Chromium across image layers, speeding up rebuilds.
