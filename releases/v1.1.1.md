# DocuMine v1.1.1

**Released:** May 12, 2026

Single-port serving and Windows CLI fix.

---

## What's New

### Single-Port Serving

`documine serve` now serves both the API and the built frontend on the same port. Open `http://localhost:3120` and get the full editor — no separate dev server or reverse proxy needed.

- Root `/` serves the frontend HTML
- API at `/api/*`
- SPA routes (share links, etc.) fall back to `index.html`
- `/health` remains a plain-text health check

### Windows CLI Fix

Fixed a path resolution bug on Windows where `new URL(import.meta.url).pathname` produces a leading slash (`/C:/...`), causing `documine serve` to fail with `Server not found at ...`. Replaced with `fileURLToPath`.
