# DocuMine v1.1.2

**Released:** May 12, 2026

Fixes the npm package to include all required dist files.

---

## What's Fixed

The `files` field in `package.json` was missing `dist/code-block-style.js`, which is imported by `pdf-export.js`. Running `documine serve` after a global install crashed with `Cannot find module './code-block-style'`.
