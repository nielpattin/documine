# DocuMine v1.1.3

**Released:** May 12, 2026

Fixes the npm package to include the built frontend files.

---

## What's Fixed

The npm package was missing `apps/web/dist/` (the built frontend) because `apps/web/.gitignore` excluded the `dist/` directory and npm respects nested `.gitignore` files during pack.

Added an empty `apps/web/.npmignore` to override the nested `.gitignore` for publishing, and a root `.npmignore` to prevent the root `.gitignore` from filtering out published files.

Now `documine serve` correctly serves the frontend on the same port.
