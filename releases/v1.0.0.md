# DocuMine v1.0.0

**Released:** May 2, 2026

First major release. Adds shareable PDF export links and a refreshed visual style across the application.

---

## What's New

### Shareable PDF Export Links

Each PDF export can now generate its own unguessable share link, powered by UUID tokens. Share a specific export with anyone via `/pdf/:token` without requiring owner authentication.

- **Per-export tokens:** Each export gets a unique, cryptographically random token. Tokens are persisted to disk and survive server restarts.
- **No enumeration:** Tokens are UUIDs, so other exports cannot be guessed through a note's share ID.
- **Revocable:** Revoke any individual share link at any time. Once revoked, the link returns a 404.
- **Cleanup:** Stale tokens pointing to deleted exports are automatically purged on access.
- Share status (token and URL) is now visible in the export summary response.

### Refreshed UI

- Updated dark theme with a cooler color palette and improved contrast across all surfaces.
- Accent color changed from white to blue for better visual hierarchy.
- Updated shadow, border, and spacing tokens throughout the stylesheet.
- Editor font-size bumped to 16px for better readability.
- Responsive preview-collapse breakpoint lowered to 600px for improved mobile experience.
